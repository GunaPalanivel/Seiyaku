# Seiyaku product requirements

This PRD defines the product to build, its interfaces, phased delivery and
acceptance gates. It contains requirements, not research reports or completed-work
claims. Research, audits, experiment code, receipts and local environments remain
outside version control under `.idea/`.

| Document | Purpose |
|---|---|
| [01-product-requirements.md](01-product-requirements.md) | Outcome, scope, functional requirements and constraints |
| [02-system-design.md](02-system-design.md) | Components, interfaces, isolation and selection boundaries |
| [03-phased-build-plan.md](03-phased-build-plan.md) | Small deliverables with dependencies, acceptance and success criteria |
| [04-validation-and-release.md](04-validation-and-release.md) | Required tests and release checks |
| [05-risk-register.md](05-risk-register.md) | Product risks and closure requirements |
| [06-backlog.md](06-backlog.md) | Issue-sized work packages; no assignments |

The [draft backlog](06-backlog.md) provides work-package IDs and dependencies.
Keep issue scope aligned with this PRD.
Issue creation and assignment remain separate team decisions.
