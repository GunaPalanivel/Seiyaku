# Phased build plan

Phases identify milestones. Follow dependencies, not numbering alone: trusted
evaluation and protected release selection precede the official pilot. Each phase
must produce its own evidence before promotion. Owners and dates are chosen later.

| Phase | Actionable deliverable | Acceptance criteria | Success criteria |
|---|---|---|---|
| 0 | Pin/import starter; verify legal public-data access, schemas, image digest, limits and native-provider mode | Reloadable manifests, no secrets, actual runtime and unresolved rules explicit | One legal public toolkit run and bounded existing-entitlement request complete |
| 1 | Implement ODIMCF control/validator and exact pilot archive | Complete identities, directed paths, capacity/rejection checks and raw objective; isolated extraction runs | Organizer accepts the authorized exact pilot and establishes a real baseline |
| 2A | Implement contracts, independent evaluator and selection transactions | Read-only inputs, every objective/field checked, complete ledger and save recovery | Tampering/false-fitness controls rejected; valid improvements ranked correctly |
| 2B | Implement DARP timing, construction and bounded repair/fallback | Mandatory service, pairing, precedence, capacity, windows, ride/route limits; timing agrees with independent control | Actual public cases produce complete checked schedules within the envelope |
| 2C | Implement SPP, OP, SCFLP and VRPDDP controls/validators | Sparse side-constrained cover; connected nonmetric tours; shared scenario openings; full delivery/pickup loads and field agreement | Complete actual current-stage coverage with no unexplained public failure |
| 3 | Improve the largest measured objective/failure deficit | Frozen strongest control, matched budgets, untouched legal real cases, complete failure accounting | Positive retained uplift without lost coverage, then official confirmation |
| 4 | Implement bounded statement-to-solver generation and selection | Provider bridge, request accounting, replay, protected holdouts and no manual core edits for a new slug | Fresh-family adaptation beats matched controls without losing feasible coverage |
| 5 | Freeze dependency/rights records and exact full-stage release | Every selected folder runs independently; process limits, archive identity and rollback verified | Teammate reproduction and authorized organizer acceptance of exact bytes |
| 6 | Capture and cover the actual qualification-stage task set | Full stage manifest, no missing required solvers and explicit zero-case ledger | Highest attainable complete official score and organizer-confirmed qualification |
| 7 | Capture final rules and rehearse exact final workflow | Interface, budgets, permitted artifacts/interventions and every requirement mapped to completed checks | Rank 1 on the organizer's final Main evaluation |

## Work sequence

1. Capture real contracts, access and runtime before benchmarking.
2. Establish trusted inputs, independent validation, complete accounting and
   protected incumbent storage before trusting fitness-driven selection.
3. Prove one official end-to-end pilot. Diagnose exact I/O, contract or runtime
   failures before expanding framework complexity.
4. Close mandatory-service and representation risks, then cover every published slug.
5. Improve measured deficits while retaining previous checked controls.
6. Rehearse fresh-family adaptation and the actual published final protocol.

Use [backlog work packages](06-backlog.md) for issue-sized scope. Domain work may
proceed independently after interfaces are frozen; serialize shared-host benchmarks.
No staffing/hour estimate substitutes for acceptance or performance evidence.

## Stop rules

Access/image failures block official-envelope claims. Unknown final rules block
final-readiness claims. Quota failure stops new provider requests without purchases
or account workarounds. Failed construction is not an infeasibility proof. Missing
or infrastructure-failed runs cannot be hidden in averages.

Submission is a separate authorized action, bound to exact target and archive.
No fixed local score or test count guarantees the final competitive outcome.
